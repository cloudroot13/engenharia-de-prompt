# 🎓 StudyFlow AI

## 📌 Sobre o Projeto

O StudyFlow AI é uma aplicação desenvolvida utilizando conceitos de Low Code e Inteligência Artificial com foco na organização de estudos para estudantes.

A plataforma permite que o usuário informe:
- matérias que deseja estudar
- quantidade de horas disponíveis
- data da prova

Com base nessas informações, o sistema gera automaticamente um plano de estudos personalizado.

O projeto foi desenvolvido como atividade acadêmica da disciplina relacionada a Low Code, No Code e Vibecode.

---

# 🎯 Objetivo

O principal objetivo do projeto é auxiliar estudantes na organização da rotina acadêmica através de automação e fluxos visuais utilizando ferramentas low code.

Além disso, o projeto busca demonstrar:
- automação de processos
- integração de IA
- criação rápida de aplicações
- desenvolvimento visual sem programação complexa

---

# 🧠 Problema Identificado

Muitos estudantes possuem dificuldade em organizar uma rotina eficiente de estudos, especialmente em períodos de provas e atividades acadêmicas.

O StudyFlow AI foi criado para oferecer uma solução simples, intuitiva e automatizada para esse problema.

---

# 🚀 Funcionalidades

✅ Criação automática de plano de estudos

✅ Interface simples e intuitiva

# 🖥️ Estrutura da Aplicação

A aplicação possui:

- Campo para matérias
- Campo para tempo disponível
- Campo para data da prova
- Botão para gerar plano
- Área de exibição do resultado

---

# ⚙️ Tecnologias Utilizadas

- Bubble.io
- GitHub
- Inteligência Artificial
- Fluxos visuais
- Conceitos Low Code / No Code

---

# 🔄 Funcionamento

O usuário preenche os campos com:
1. Matérias desejadas
2. Horas disponíveis
3. Data da prova

Após clicar no botão “Gerar Plano de Estudos”, o sistema exibe automaticamente uma sugestão de cronograma de estudos.
